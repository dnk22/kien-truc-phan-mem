## Render lại hoàn toàn cục bộ

Java Zulu17.0.18; PlantUML1.2025.10 JAR cố định, Smetana. Không gửi source đến public renderer. Không có dot/plantuml executable; `-version` in phiên bản nhưng exit16 do không có dot. Lệnh check/render dưới đây dùng Smetana exit0. Tham khảo [PlantUML Smetana](https://plantuml.com/smetana02).

```sh
# Tải artifact công khai; giữ JAR ngoài repository.
curl -fL https://repo.maven.apache.org/maven2/net/sourceforge/plantuml/plantuml/1.2025.10/plantuml-1.2025.10.jar -o /tmp/plantuml-1.2025.10.jar
python3 scripts/documentation/render-uml.py --jar /tmp/plantuml-1.2025.10.jar
```

Script gọi Java headless UTF-8 `-Playout=smetana -checkonly`, sau đó `-tsvg` và `-tpng` vào rendered/svg và rendered/png. [Lệnh/exit/duration](../evidence/final3/render-commands.json), [log](../evidence/final3/render.log). Không tự thay version JAR. Khi sửa UML cần render, xem lại hình, cập nhật hashes/visual review/manifest trước dùng package.
